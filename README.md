# Rifatul Azim — Professional Portfolio

A responsive personal website featuring the supplied portrait, four roles, four education entries, LinkedIn skills and Facebook / LinkedIn links.

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and the complete `assets/` folder to the repository root.
3. In Settings → Pages, select Deploy from a branch → main → /(root).
4. Wait for the deployment URL. Test on desktop and mobile.
5. Add the public URL to Google Search Console and request indexing. Indexing is not guaranteed.
